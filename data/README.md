# Dataset

This project uses the US Accidents (2016–2023) dataset.

The original dataset contains approximately 7.7 million accident records collected across the United States between 2016 and 2023.

## Dataset Source

Dataset name:

## US Accidents (2016–2023)

The dataset was originally obtained from Kaggle.

Due to the large size of the original dataset, the full raw CSV file is not included in this repository.

## Project Sample

For this project , a representative sample of **500,000 accident records** was extracted from the original dataset.

The sample preserves the original year distribution proportionally across the available years.
